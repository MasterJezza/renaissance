# Skogsmarknaden i Lettland 2020–2026

Marknadsanalys av sålda skogsfastigheter och skogsbolag i Lettland 2020–2026:
marknadstrender, prisutveckling per hektar, större transaktioner och nyckelaktörer.

## Filer

- `Lettland_skogsmarknad_2020-2026.pdf` – färdig rapport (A4).
- `rapport.md` – rapportens källtext i Markdown (redigera här).
- `style.css` – layout för PDF-utskriften.
- `build.sh`, `build-pdf.js` – bygger PDF:en från Markdown.

## Bygga om PDF:en

Kräver `pandoc` och Node med Playwright/Chromium.

```bash
./build.sh
```

Dataläge: t.o.m. oktober 2026. Rapporten är ett marknadsunderlag, inte investeringsrådgivning.
